# Plumb v0.18.19

Plumb now owns one closed document surface. `agent`, `architecture`, `design`,
and `brief` derive their exact target files and text magnitude from the binary;
repositories declare only a strategy, objective source seats, and human
affirmation seals.

Doctor reads the Git index and worktree bytes once for vocabulary and document
laws. It reports tracked Markdown outside declared document targets and
`docs/CHANGELOG/**`, names every source binding that invalidated a target, and
refuses unaffirmed source, target, or topology changes.

`plumb document` prints canonical source and target seal proposals after a
human has read both sides. It never edits the manifest. The target seal binds
the selected strategy, brief name, ordered source topology, and target bytes;
source seals are retained independently so one changed seat is visible.

Exact release compilation now compares the previous public stable commit with
the frozen candidate. Each language's `INDEX.md` plus `MIGRATION.md` is bounded
by `clamp(4 * ceil(sqrt(diff_units)), 120, 800)`, where diff units are textual
additions, deletions, and changed-path count. The release seal retains the
base, candidate, diff identity, magnitude, and language document seals.

This release is the bounded compatibility bridge. Legacy `[skill]` and
`[[lock]]` remain valid only when no `[[document]]` declaration exists. The two
models cannot coexist. The following enforcement release removes the legacy
schema and `plumb lock` after governed repositories migrate.
