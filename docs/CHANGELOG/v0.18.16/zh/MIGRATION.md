# 迁移到 Plumb v0.18.16

升级前，先从仓库中移除该退役词的所有活引用。在 `docs/CHANGELOG` 之外，按大小写
不敏感的方式搜索 tracked 路径名与 tracked 文件内容。该目录下的历史条目已豁免，
无需改动。

声明"本仓库不使用该退役产品"同样是一处引用，也会被报出。应改写为命名缺席的
能力，而不是命名缺席的产品。若所在句子已经给出类别——某种 runtime model、某类
wrapper、某项生命周期职责——那么产品名本身就是冗余项，直接删除即可，断言强度
不变。

不要用变体拼写、拆分字符串或仓库本地排除来绕过该法条。词典不接受这些做法，且
匹配不设词边界。

如果你的仓库自带 Doctor fixture，请注意：不是 Git 仓库的受管目录现在会在这条
法条上报 blind。应把这类 fixture 初始化为仓库，而不是把该结果当成缺陷。
