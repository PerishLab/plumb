# Plumb v0.25.0

## 镜像的 payload 改从发布它的权威面取

包着二进制的镜像原先从本地归档目录读那份 archive，并用那个文件的摘要给自己贴标签。
「这个镜像装着那个产物」这句声称，靠的是一份**只有 runner 见过**的文件；而渲染出的
lane 的投影 job 里根本没有这样一个目录，于是这个介质在那里无法投影。

归档不在时，payload 现在来自**已发布的那次发布**：封印点名那个对象，对象从权威面取回，
其摘要必须等于封印记录的那一个，否则投影拒绝。于是消费者读到的标签，就是公网权威面所
提供的那个对象的摘要 —— 这本来就是那句声称的意思。

手里有归档的 lane 行为不变：共享 workflow 在发布任何东西之前就构建镜像，它手里只有归档。
渲染出的 lane 是在封印已经存在之后才投影，所以它才问得起权威面。
