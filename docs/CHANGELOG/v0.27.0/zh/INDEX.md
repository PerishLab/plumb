# Plumb v0.27.0

大多数在拿掉同一样东西:一句**立在机制旁边、而不是从机制身上取来**的说法 ——
一份关于某个命令做什么的第二文档，一个没人量过的常数，一个在摘要唾手可得时却被接受的名字。

## 锁契约是一件事，所以它是一个族

**`plumb stable` 没有了。** 它的动词现在是 `plumb release prepare|pick|freeze|rejoin`，
而 `plumb release stamp|retract` 造与撤一个发布点，两种通道都管。

契约是**版本号 + 锁定形式 + 投影面**。其中两样在 `release`，第三样不在:**一条线，就是把一个
版本号钉到某个 commit 上并使之永久的那套装置** —— 那就是锁定形式。它看起来像一个独立的
生命周期，只因为它有自己的 git 对象;而一条线为一次发布而切，承载那次发布的点，发布结束时
合回去。

**交替让它显形**:按顺序写出来是 `stable prepare → stable pick → release stamp → dispatch
→ stable freeze → release stamp → dispatch → stable rejoin`，**每一个箭头都跨过一次族边界**。
那道切分切在**实现介质**上 —— 一侧 git ref，一侧 authority —— 一个实现细节戴着族名。

**exact 发布从此由机制打点起步**:那套机器一直都在(带注释、拒绝移动已立住的点)，
但只有 `freeze` 够得到它，于是开一个 beta 要手敲 `git tag`。`freeze` 不再打点，
它原本由构造保证的不变式被搬到查得出来的地方 —— **stable 派发在它的点未立于线头时拒绝**。

`rejoin` 曾在两族里各有一个，意思还不同:一个**做**合并，一个**证**拓扑。现在是一个动词:
给版本号就做并自证，不给就从运行的环境里读、只证运行已经做过的事。**`ship` 一个字没动** ——
它对着锁好的东西执行，二进制只是它的一个 adaptor。

## 干跑走的就是它将要走的那条路

`--dry-run` 印的是一份**另写的文档**，手写在它声称要描述的代码旁边。两个漂移方向都实测到了:
`plumb land` 计划里写着一个客户端从不发送的查询，`plumb stable freeze` 印两行、实做六步 ——
**第六步是 `git tag` 并推送**，一个预览从未提及的不可逆动作，出现在发布走到不可逆之前唯一
的那次审查里。

挡住「只走一条路」的，是预览没法知道它没做过的事。**但这个障碍是自己设的 —— 读不是变更。**
干跑现在做完所有读、只跳过写，于是它**解析**分支到底存不存在，印出它将要打 tag 的真实 commit。
每个变更都作为一个步骤声明，而那个步骤的第一个参数就是描述它的句子 —— 于是一个到达远端却
没有描述的写动作**写不出来**;读不到需要的东西时，预览**拒绝**，而从前它会印出自信的计划。

## npm 的证据是那个 tarball，不是那个名字

注册表回答「这个版本存在」时，模块适配器就跳过发布;发布之后取回 `dist.shasum` 然后**丢掉**。
npm 这条道对一次发布能作出的最强宣称，就是「有这么个名字」。

npm 能不能做得更好，此前**未知**，所以什么都没做。现在知道了，而且是量出来的:从 v0.26.0
新检出、按 lockfile 安装、stamp、pack，**逐字节复现出已发布的那个 tarball**。于是 `carried`
改读 `dist.integrity`，在发布前与发布后各比一次，任一处不符即 `published module drift`。
第一次比对**没对上**，差别是 `package.json` 的键顺序 —— `stamp` 解析进一个会排序的 map。
**这里的可复现性靠的正是它，而且是无意中靠上的。**

## 介质要等发布真的立住了才投影

投影 cargo / npm / oci / chart 之前那道门，读的是**本机磁盘上的 capsule**。capsule 是上传计划，
产生在任何东西被上传之前，所以它证的是「这台机器编译过这个版本」，不是「这次发布立在什么
地方」。它现在把 seal 从公网 authority 读回来比对摘要，复用 `plumb ship binary verify` 已有的
那次 fetch。它只查 seal，且只对产品真正声明了的介质开火。

## 渲染出来的 stable lane 会推进指针了

**移动 manager 与推进共识指针是两个操作**，而渲染出来的 lane 只跑了第一个。于是一次 stable
发布把对象都发了、报告"已激活"，而通道仍指着上一个版本;随后 smoke 装到仍然 canonical 的
那一版，报出它们本来就是为了抓这件事而存在的不匹配。

**v0.26.0 是带着这个缺陷发出去的。** 它自己那次靠手工收尾;`sidecar v0.8.0` 是第一个用那一版
渲染的 lane 发 stable 的产品，**发不完** —— 写指针那个动作需要的凭据只存在于 lane 内部(#346)。
**任何用 v0.26.0 渲染过 lane 的仓库都带着它**，重新渲染是消除它的唯一方式。

## 量出来的数

附件能声明多宽，原本是一张表，而表里的数字就是「走到它面前的那些产品恰好需要多少」——
**按观测到的压力定出来的上限，是产品给自己发的许可，只是多绕了几步**。`ceiling = 10` 是所有
附件共用的一个数。agent 与 design 的文档预算写死 320 —— 一个不量任何东西的数字，出现在读者
最先打开的那份文档上;它们现在量自己所描述的源，于是守卫**在它原本什么都没防的地方收紧**，
在仓库挣来的地方让开。

## packport 成为 rejoin

`packport` 不是一个词，而 `backport` 也不是这个操作:backport 把修复带到更老的线上，这个是把
冻结的线合回 main。`rejoin` 顺着生命周期读得通:prepare、pick、freeze、rejoin。旧词进退休
词典 —— **这正是把一次改名变成机制的东西**:任何仍带着它的被跟踪字节即 out of true。

## 更小的几件真事

`oci` 在输入台账里没有对象，于是那个回答「哪些介质动过」的封印对镜像只字未提。镜像现在是
一个对象:它的 `Containerfile`、`[release.depends]` 添的边，以及当镜像包着本次发布的归档时的
版本号。

Debian 包把 semver **原样**写进 dpkg 的 `Version`，而那里 `-` 分隔 upstream 与 revision、
空 revision 排在有 revision 之前 —— 于是预发布版本宣称自己比它前面那个正式版还新。
现在只有第一个 `-` 变成波浪号。

落地的 commit 把自己的标题说了两遍(标题取 `%s`、正文取 `%B`)。`doctor` 会点名版本与运行中
二进制不一致的已安装 brief，这是**观察而非判决**。Cargo 排练会说出哪些包它排练不了 ——
一个附件是一个整体，包与包精确互钉。生成 v0.26.0 的自举已撤除。
