# Plumb v0.26.0

七刀，形状是同一个：机制在某处信了一件它没有量过的事。

## 发布按自己记下的基准面判决，不再去问注册表

依赖法要求一等公民的锁解析到**活的** stable latest，而 `plumb doctor` 是在它运行的
那一刻去问注册表的。于是一次发布把生成器冻住了，却让外部世界在它底下挪动判决：Plumb
一发版，所有依赖它的线当场变红 —— 产品一个字节都没动。

`plumb stable prepare` 现在把这条线将要据以判决的答案记下来 —— 依赖法会咨询的每一条
一等公民各一条 —— 作为**该线的第一个 commit**，落在 `.plumb/releases/<version>/datum.json`。
在这条线上 `doctor` 读记录；不在这条线上，`main` 继续追活 latest，因为漂移检测仍是它的
职责，而可复现是这条线的职责。发布线上没有基准面即 out of true。

`.plumb` 下的座位是 Plumb 自己的，所以源投影排除它，正如排除 `docs/CHANGELOG` ——
切一条线不会作废文档封印。`freeze` 接受这个没有 cherry-pick 出处的 commit，因为它**自证**：
只碰一个已知叶子，且内容能按它点名的那条线解码。

## source seat 里不许有 Git 不跟踪的东西

文档封印投影的是 index，而没有任何地方问过「这个座位里还坐着什么」。一个没被跟踪的文件
干脆就不存在，于是记下来的封印代表的是**另一棵树**，而 `doctor` 一直绿到那个让差别对别人
显形的提交为止。

声明的 source seat 里有未跟踪叶子，现在是 out of true，且 `plumb document` **不再为那个
座位给出任何封印提案** —— 而不是交出一个它兑现不了的封印。算不算数由 Git 自己的 ignore
规则决定，所以答案只有两个：`git add` 或 `.gitignore`，两者都是一句明确的话。

## 一个附件就是一个对象，且投影永不跳过

逐包簿记发出去过一对坏东西：macro crate 到了注册表，而**精确要求它**的那个库没到，于是
已发布的那个 crate 从任何地方都不可达。一个附件声明了两个包，而那里只有**一个单位** ——
proc-macro 必须独立成 crate 是语言强制的，两者同生共死。

对象现在就是附件。它声明的每个包共同构成一份输入摘要、共用一个版本、永远一起发；于是
没有「各自的版本」可以拖后，也没有 pin 表可以推导。

**投影永不跳过。** skip 的立论建立在「逐对象独立版本」上，而那个前提早被撤回、skip 却留着；
只要发布物的身份含版本号，不发就不是省事，是在版本序列上打一个后面任何一次发布都补不回来
的洞。输入摘要作为「什么动过」的证据留下来，不再决定任何事。

## 输入摘要量的是 Git 记录下来的东西

那份摘要读的是工作树里的字节，于是一次发布量的是 runner 磁盘上那份，而不是它被要求构建的
候选。现在它覆盖每个叶子的 path、mode 与**记录的 object id**：改动被记录时答案就动，工作树
只是脏时答案不动。

## watch 到整个 run graph 结束为止

run 报 success 而 job 列表为空，读起来是完成了；run 报 success 而其中一个 job 失败了，读
起来也是完成了。发布「绿着回来却什么都没发」正是这么来的。判决现在取自整张图，而且它是
任务列表的一个纯函数。

两处拒绝也不再打哑谜。forge 的错会点名 Plumb 当时正在做的那个操作；`head out of date`
（Forgejo 对任何它不喜欢的 head 都这么说）会点名这个 pull 实际站在哪个 commit 上。

## 该由机制盯着的数字，交给 Plumb 管

一个附件可以声明多少个包，原先无人管；每条渲染 lane 跑的 forge 镜像，是有人手改的常量。
两者现在都住在 Plumb 的规则目录里。放宽一个宽度就是改 Plumb —— 这正是要点：产品不能靠
声明给自己发一张许可。

**permitted 与 exercised 不是同一件事，所以是两张表。** 声明超过 Plumb 自己真发布过的宽度
只报 noted，绝不拒绝 —— 两者的差额是唯一能说出「这条路从没跑过」的东西。

## packport 迟到，在撞车之前就被拒绝

packport 读起来像收尾，于是被留到以后；而以后，下一条线就切在了 `main` 从未见过的提交
上面。`prepare` 与 `freeze` 现在在「最后一个 stable 点不是 `origin/main` 持有的提交」时
直接拒绝，并点名那次能了结它的 packport。证据是一个 tag 加一次 `merge-base`，不碰任何网络。
