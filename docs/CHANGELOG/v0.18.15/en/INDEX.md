# Plumb v0.18.15

## Closed skill limit strategies

Repositories with source skill seats now select one Plumb-owned limit strategy
in `plumb.toml`. A strategy closes both the admitted root file enumeration and
the aggregate text magnitude; repositories cannot provide raw `files`,
`limit`, or formula parameters.

The initial `brief` strategy admits `SKILL.md`, `PATHS.md`, and `SCENARIOS.md`
and derives their shared budget from production source scale. Doctor refuses a
missing or unknown strategy, an open file set, unread evidence, and excess
text.
