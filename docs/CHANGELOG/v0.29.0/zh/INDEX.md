# Plumb v0.29.0

## 配置不再需要一次发布才能生效

Plumb 的法条与 lane 模板现在作为不可变对象发布到 Plumb 自己的 depot，同步下来的
座位先于编进二进制的字节被采用。编进去的字节**永久保留**：一个不连上网就跑不起来的
工具，恰恰会在最需要它的地方失效。

法条目录原本承载的那条保证原封不动地活了下来。depot 的权威是 Plumb 的，由 Plumb
自己的 lane 从 Plumb 自己记录在案的 roots 写出，所以产品仍然不能靠声明给自己发一个
形状，它只能跟随 Plumb 发布的那个形状。

一个版本就是一个时间戳，仅此而已 —— 全序不需要动词来推进，也不需要判断来比较。
指向当前版本的通道指针是这个存储里唯一可移动的对象。任何仓库都不钉住。

## 两条法立在这个座位上

`depot.roots-published` 断言：仓库记录的每一个配置 root 都被持有的版本以相同摘要
携带。`depot.schema-supported` 断言：运行中的二进制不低于该版本声明的下界。两条都
只读本机座位、永不取网，所以陈旧的座位是一个观察，而**存在却读不出的座位是 blind**。

## 发布说明搬了家，并且变成可变的

发布说明是一个**席位**，不是一道门。任何已发布的版本都有一个已知地址放迁移指导，
一份只写着「详见源码」的说明**同样占住了这个席位**。

说明可变，而它可以可变恰恰是因为 ship 不可变。身份只在一处付账 —— 版本与它的封印
——所以一份谈论那个版本的说明没有能力对「它在说哪一版」说谎。它只能变得更好，而这
正是迁移指导需要的：一个版本发出去三天后才发现的坑，属于那一版的说明。

编译一次发布不再校验说明，**所以一份说明再也没有能力弄挂一次发布**。封印不再携带
changelog 证明；在这条规则之前写下的那些仍被读取，永不再写。

## 座位有了唯一真相源

`plumb::seat` 命名一个工具可以持有的三个座位，Plumb 自己的全局座位从此经由它取得，
而不再就地拼出一个。

## 底座不再被要求是最新

`deps.first-party-stable-latest` 不再因为一个仓库消费的 Plumb 不是线上 stable
latest 而拒绝它。现在由 depot 的下界决定它是否够新。一个**根本读不出来**的依赖仍然
拒绝。
