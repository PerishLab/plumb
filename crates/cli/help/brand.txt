Verify one explicitly declared brand consumption boundary after its normal build.

An empty [brand] table in plumb.toml activates the bounded contract. All root and
apps/* Svelte/Vite applications are discovered; a new app is not skipped because
it is not named web. Each requires one static configuration, a real imported
Design plugin call and imported official Hero/Navigator marks. The default HTML
carrier requires a literal head product/HTTPS origin. Dynamic configuration or unsupported source stays
unqualified. Additional config imports, resolution overrides and transforms are
outside the qualified scope. No repository configuration is executed by this command.

Unrelated each/snippet/await templates do not invalidate an imported brand mark
outside their scope. The AST still inspects all template tags. Brand references
inside those lexical scopes, const or slot bindings in a brand-bearing scope,
snippet names shadowing an imported brand component and module/context scripts
remain unqualified. Local aliases and arbitrary dynamic component semantics are
not resolved; unrelated business components are not reclassified as brands.
Literal generics in a TypeScript script are verified as type parameters, without
creating runtime component bindings. Dynamic/malformed generics, extra script
attributes and generics on JavaScript scripts stay unqualified.

The compiler plugin must be imported, called once without arguments, with no
automatic Svelte config, app package browser mapping or producer self-reference.
Package, lock, app config, HTML and source inputs must be tracked regular files.

The fixed official registry supplies exact stable npm metadata and archives.
Acquisition runs no repository/package code. Archive SHA512 must match the
actual pnpm lock. Complete Crest/Design distributions, installed package files,
the official manifest, every receipt selection and actual output bytes are
verified. The default HTML carrier requires matching generated data-crest images;
CSR-only output and unreachable source-only declarations stay unqualified there.
The receipt authenticates no publisher by itself. Captured archive
references validate content; supplied/deserialized references alone authenticate
no origin. Guard captures its own originals and binds them to source/world.

An explicit bounded CSR carrier is available:

[brand]
mode = "views"

It requires the standard Design Views import/root/mount program, root Vite base,
login:false, one src/views/index.svelte root route and one unconditional imported
brand under plain formal Shell/Frame layouts. Other aliases, bootstraps, conditional
brand placement and route graphs remain unqualified. Headless consumption allows
no brand plugin head option, requires explicit receipt head:null, and permits only
an empty data favicon instead of graphical head media. Missing head is not null.

The plumb.brand/v2 report distinguishes formal origins, source/image outputs and
the rendering obligation. Views mode records the local output module and digest;
that digest proves neither source/bundle equivalence nor actual rendering. Its
rendering field requires an independent browser; browser is always unverified.
HTML image observation is also separate from browser appearance. Exit 0 qualifies
only the stated carrier's source/origin/official-image relationship.

Additional unchanged copies can be declared without duplicating geometry:

[[brand.copy]]
asset = "plumb/sign/full/light/png/48"
output = "apps/web/public/favicon.png"

The asset identifier is resolved from the official manifest. Output paths must
stay inside tracked regular repository source. They are verified before action
reuse and after execution. The current Guard contract requires a pnpm input
world; other static package/host worlds remain unqualified. Unknown selections, changed bytes, missing outputs,
unreadable sources and unsupported worlds refuse; no repair or fallback occurs.
Ordinary SVG/business graphics are not universally classified as brands.

This proves bounded source/origin/output relationships, not arbitrary image
semantics, browser presentation, all runtime requests, other renderers/native
hosts or estate-wide activation. Absence of [brand] proves no adoption. Guard
verifies an activated contract after the web build; distribution, installation
and real land canaries remain separate rollout evidence.

JSON is written to stdout with --json. Exit 0: qualified within the stated
boundary; exit 1: refused or unqualified. Credentials are used only to acquire
official metadata/archive bytes, never to execute repository code.
