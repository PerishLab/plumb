Define one immutable distribution marker.

Release owns identity, not distribution. A marker is one annotated Git tag on the
head of its release line, naming the version and, for a stable marker, the
prerelease it promotes. Stamp creates it: a beta or rc marker takes the next
number on the line, and a stable marker takes the version of an rc or beta that
already shipped from the same commit, preferring the rc. Shipped means what
wharf's distribution.json beside the marker's seal says: the prerelease is
recorded complete at that commit. Retract removes only a marker nothing of
which is public: its distribution record decides, and a marker without one is
judged by its seal. Managers renders the scripts a version installs with.

Rejoin settles the standing stable marker into main. It names no version: the
debt is the highest stable marker origin holds, and it is owed until main holds
that commit. Rejoin records only the topology, a commit with main's own tree
whose second parent is the stable commit, so it carries the Guard proof main
already holds and lands through a pull with that proof as its guard status. A
release line that carries changes main lacks is refused; land them into main
first.

A release line is release/vX.Y.Z and carries one version. Open cuts it from
main, or from a lower stable marker for a fix that ships on its own; a version
that stands as stable never reopens. Close deletes a line once its stable
marker is home and deleting it loses nothing: its head must be main's or a
marker's, and the markers keep its history. A version counts as released when
its stable marker stands or the release authority holds its stable seal, as
lines stamped before stable markers were tags do. A line that never reached
stable closes only with --abandon.

A stable marker leaves obligations behind: its distribution completed, its
commit merged home into main, its changelog lodged on Depot, its skill where
the product declares one, and its line closed. Open, stamp and ship dispatch
refuse any later version, on any channel, while the highest stable below it
still owes one, and name the command that settles each: ship dispatch, release
rejoin, depot consign and release close. Owed
reports each obligation of that stable marker, settled or owed.

Release never builds, compiles, publishes, or edits a version line. Wharf decides
release identity at distribution time, so sources declare version 0.0.0 and a
binary is bound to its marker after it is built. Use ship with the marker to hand
the distribution to wharf.

A marker never moves. A stable marker refuses a version that already stands.
