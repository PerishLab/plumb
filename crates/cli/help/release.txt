Define and verify one immutable distribution marker.

Release owns identity, not distribution. A marker is one annotated Git tag that
binds the product, repository, version, channel, commit, tree, datum digest, and
stable promotion proof. Show and verify resolve that complete identity. Stamp
creates it only from a proved source point; a stable marker additionally refuses
unless its version line is frozen. Retract removes only an unpublished marker.

Release never builds, compiles, publishes, activates, or edits a version line.
Use version to project repository identity and govern the line. Use ship with the
resulting marker to distribute immutable resources. Ship invokes depot to move
the marker-bound mutable projections after every immutable resource reads back.

A marker never moves. Every ship and depot retry names the same marker and
revalidates it before and after mutation.
