Define one immutable distribution marker.

Release owns identity, not distribution. A marker is one annotated Git tag on the
head of its release line, naming the version and, for a stable marker, the
prerelease it promotes. Stamp creates it: a beta or rc marker takes the next
number on the line, and a stable marker takes the version of an rc or beta that
already shipped from the same commit, preferring the rc. Shipped means what
wharf's distribution.json beside the marker's seal says: the prerelease is
recorded complete at that commit. Retract removes only a marker nothing of
which is public: its distribution record decides, and a marker without one is
judged by its seal.

Rejoin reports whether the standing stable marker is home in main. It names no
version and writes nothing: the debt is the highest stable marker origin holds,
and it is owed until main holds every change that commit carries, that is until
merging it into main would leave main's tree unchanged. A stable commit already
in main's history is home. Main takes only squash merges, so no merge commit
records the release line; while the marker is owed, rejoin names the paths
whose changes main lacks, and the remedy is to land the release line's changes
into main.

A release line is release/vX.Y.Z and carries one version. Open cuts it from
main; a version that stands as stable never reopens. Close deletes a line once
its stable marker is home and deleting it loses nothing: its head must be
main's or a marker's, and the markers keep its history. A version counts as
released when its stable marker stands or the release authority holds its
stable seal, as lines stamped before stable markers were tags do. A line that
never reached stable closes only with --abandon.

Release versions only ascend: a higher version always names a later release.
Open refuses a version, and stamp and ship dispatch refuse a marker, unless it
exceeds every other marker origin holds when they run, stable or prerelease,
and the refusal names the highest of them. A marker published after a line
opened therefore still refuses a lower one. A fix for an older release ships
as the next higher version; no line is cut from a lower stable marker.

A stable marker leaves obligations behind: its distribution completed, its
changes held by main, its changelog lodged on Depot, its skill where
the product declares one, and its line closed. Open, stamp and ship dispatch
refuse any later version, on any channel, while the highest stable below it
still owes one, and name the command that settles each: ship dispatch, release
rejoin, depot consign and release close. Owed
reports each obligation of that stable marker, settled or owed.

Release never builds, compiles, publishes, or edits a version line. Wharf decides
release identity at distribution time, so sources declare version 0.0.0 and a
binary is bound to its marker after it is built. Use ship with the marker to hand
the distribution to wharf.

Authority reports the Guard authority a bound binary's proofs carry: its
producer, vX.Y.Z@commit, and its Depot mark. Wharf records it as the guard field
of that release's seal, which is where Authority::stable() reads it.

A marker never moves. A stable marker refuses a version that already stands.
