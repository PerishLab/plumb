Dispatch one release marker to wharf.

Ship is the thin entry point of distribution. It confirms the marker stands on
the product repository, dispatches wharf's ship workflow with the repository and
the marker, and can watch the run to completion. Everything else happens in
wharf: it derives the channel and version from the marker, reads what to build
from the product's own manifests, binds each binary to the marker, publishes
every declared medium, and records the run.

Dispatch runs in the product's repository, whose origin names the repository
it dispatches; --repo, when given, must name that same origin. It refuses while
the highest stable marker below the one it dispatches still owes anything, as
stamp does; plumb release --help names those obligations.

Ship carries no credentials and holds no plan of its own. A product repository
keeps no distribution secret; wharf is the only writer.

Recovery repeats the same marker. Wharf reuses the work whose inputs are
unchanged, runs what is missing, and refuses to publish different bytes under a
marker that already stands. Depot generations travel the same marker on their own
path; ship never calls Depot, and Depot never waits for a ship run.
