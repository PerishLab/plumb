Dispatch one release marker as one distribution transaction.

Ship accepts an immutable marker created by release and dispatches the single
ship workflow carried by Plumb. Binary, Cargo, npm, OCI, chart and worker
versions are immutable plan nodes inside that transaction. A marker-exact
configuration generation precedes manager smoke without moving latest; mutable
channel, manager, worker-deployment, skill and configuration-latest projections
are marker-bound depot phases of the same transaction. None can select another
version.

The marker is verified before dispatch and again after the run is submitted or
watched. It binds product identity, repository, release-line commit and tree,
datum digest, channel, and the stable promotion seal when applicable. A missing,
lightweight, displaced, or changed marker refuses the transaction.

Recovery repeats the same marker. The workflow plan may reuse a verified
workload or URL, run missing work, or omit irrelevant work; a successful node
does not receive another runner merely because a sibling medium is retried.

The remaining medium-shaped verbs are private execution surfaces of the
canonical transaction. They are hidden from command help and cannot establish
independent ship intent or select another marker.
