Dispatch one release marker as one distribution transaction.

Ship accepts an immutable marker created by release and dispatches the single
ship workflow carried by Plumb. Binary, Cargo, npm, OCI, chart and worker
versions are immutable plan nodes inside that transaction. Ship neither
publishes nor advances Depot projections; those independently consume the same
marker through plumb depot and cannot select another version.

The marker is verified before dispatch and again after the run is submitted or
watched. It binds product identity, repository, release-line commit and tree,
datum digest, channel, and the stable promotion seal when applicable. A missing,
lightweight, displaced, or changed marker refuses the transaction.

Recovery repeats the same marker. The workflow plan may reuse a verified
workload or URL, run missing work, or omit irrelevant work; a successful node
does not receive another runner merely because a sibling medium is retried.

Use plumb ship local --marker MARKER for explicit local bootstrap or recovery.
Default dispatch remains unchanged. Local execution requires the marker's
clean tracked checkout and consumes the same plan, configuration, tool contracts
and inventory as the workflow. Each node runs in a fresh temporary clone below
PLUMB_HOME; the caller's checkout is not a build or artifact destination.
--dry-run reports the shared graph without running nodes or creating clones.
Only nodes matching this host's declared runner platform execute. Other nodes,
or newly recorded work not yet visible in the inventory, leave the transaction
incomplete. Repeat the same marker to resume; completed work is not rebuilt.

Only marker-bound plan requests perform immutable publication. Execute requires
the marker's locked configuration and Product Profile; conflicting repository,
channel, or commit inputs refuse before publication. Medium-specific exact and
publish commands no longer exist, including binary publish.

The remaining private verbs perform local preparation or read-only diagnostics.
They cannot establish independent publication intent.
