Move a release's changelog, skill, scene and configuration onto Depot through wharf.

Depot is written by wharf alone. Plumb consigns: it places one document in
wharf's yard, a private bucket whose objects expire after seven days, and
dispatches wharf's depot workflow to lodge it. The document is addressed by
the sha256 of its bytes and created only, so a consignment names exactly what
it carries. Wharf reads it by that digest, vets it again and only then writes
the generation, so the yard is never trusted.

Consign a changelog with --kind changelog and the prepared notes in --dir; the
notes are proved against the diff budget of --version first, as plumb
changelog --prove does. Consign a skill with --kind skill and the brief in --dir:
exactly one regular file, SKILL.md, within the cap rule://seat/wayfinder sets;
any other entry in --dir is refused. A skill is written for its release and
lives only on Depot; no repository carries skills/<product>.

Consign scenes with --kind scene and their complete materials in --dir. The
nonempty directory carries only regular files and directories, never links or
special objects. Paths must be UTF-8 and anchored; file bytes and executable
modes are retained. Plumb packages materials without executing commands or
judging scene semantics; Seatrial owns selection and execution. A scene is its
own Depot kind, independent of the product it tests. Its generation remains
bound to the consigning repository's --version marker. Reading that version's
latest generation does not discover the repository's latest released version.

Consign configuration with --kind configuration and the complete rules tree in
--dir. The nonempty plain directory carries only regular files and directories,
never links or special objects, with UTF-8 anchored POSIX paths. Every .toml
file (case-insensitive) must be valid UTF-8 TOML parsing to a nonempty table;
companion non-.toml regular files are allowed. When watching the lodge, Plumb
reads back both the version standing pointer and the channel floating discovery
pointer, failing closed if either is absent, unverified, or behind --version.

The yard seat comes from PLUMB_YARD_ENDPOINT, PLUMB_YARD_BUCKET,
PLUMB_YARD_ACCESS_KEY_ID and PLUMB_YARD_SECRET_ACCESS_KEY or its _FILE
variant, which the developer profile carries: runseal :liberte plumb depot
consign. Dispatch uses the GitHub token selected by the same profile.

By default consign watches the lodge and then reads Depot back: it succeeds
only when the standing generation for the marker holds exactly what was
consigned. --no-watch returns once the lodge is dispatched.

Read a lodged skill generation with plumb depot skill, passing --version or
using the repository's declared version. Pass --raw to write only the exact
verified SKILL.md bytes to stdout for editing the next release's brief on top
of a prior generation.
