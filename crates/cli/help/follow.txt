Run or resume the registered Auto follow operation for this GitHub repository.

A current main is a no-op with no new Issue or pull. A bounded dependency delta
creates or reuses one automation-owned Auto Issue and auto/<number> branch.
Only registered first-party manifests and locks may change. The operation proves
local Guard, publishes an exact candidate, waits within a finite bound for the
required organization Guard, and revalidates before the ordinary squash merge.
Closure reads back the merge commit and successful Guard run before accepting
and closing the Issue.

If main already holds the Auto's own exact published pull and latest-stable
resolution leaves no registered delta, follow records a writer-qualified
absorption receipt, closes the pull unmerged, retires its branch by lease and
accepts the Issue, reading back each step without a new merge or Guard.
Rerunning an interrupted settlement resumes from that receipt.

State and one local repository lease live under PLUMB_HOME. A disposable clone
and empty home recover from the registered GitHub Issue, exact publication
intent, branch and pull. New local proof and delivery preparation replace old
path-bound plans. Publication intent is read back before pushing; provider
facts decide whether an interrupted write completed. Stage labels grant no
recovery authority. Provider writes are read back before resuming; a duplicate relationship, needs label, open child or
blocker, foreign branch movement, permissions refusal or failing Guard stops
the operation. A stopped operation records the available Issue, pull and failure
evidence. Repair the blocker and rerun this same command.

Only the Auto Issue's author, its operation writer, runs or settles it. Any
other identity refuses before its first write, naming the writer and itself.
Another identity's marker comment refuses every run until it is resolved,
unless the writer posted the identical comment itself; see plumb cookbook
follow.foreign-writer.

--github-command selects the caller's gh-compatible provider executable. Auto
has no Concord Member and does not repair business source or perform releases.
